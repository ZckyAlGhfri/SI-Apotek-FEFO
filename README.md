## Sistem Informasi Penjualan Apotek (FEFO Engine)

Aplikasi manajemen apotek dan kasir berbasis Web (ASP.NET Core C#) yang dilengkapi algoritma **First Expired, First Out (FEFO)** untuk otomatisasi pengurangan stok obat berdasarkan tanggal kedaluwarsa terdekat.

### Fitur Utama
- **Master Data Obat & Pemasok:** Manajemen katalog obat dan data supplier terpadu.
- **Batch & Expiration Tracking:** Pencatatan stok multi-batch per obat dengan tanggal kedaluwarsa masing-masing.
- **FEFO Cashier System:** Backend otomatis memotong stok dari batch yang paling mendekati kedaluwarsa.
- **Early Warning Alert:** Peringatan otomatis untuk obat kedaluwarsa dan stok menipis.
- **Laporan:** Rekap penjualan dan status inventaris.

### 🛠️ Tech Stack
- **Language & Framework:** C# (.NET 8) - ASP.NET Core MVC
- **Database:** MySQL
- **ORM:** Entity Framework Core (Pomelo MySQL Provider)
- **Design Tools:** Draw.io (ERD)

### 📁 Struktur Repositori
- `/docs`: Berisi dokumen spesifikasi sistem (SRS) dan diagram ERD (.drawio).
- `/src` *(akan datang)*: Source code aplikasi ASP.NET Core.
